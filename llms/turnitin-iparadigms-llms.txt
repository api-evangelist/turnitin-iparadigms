# Turnitin (iParadigms)

> Turnitin is an education-technology company providing academic integrity, similarity checking, and grading products used by schools, universities, researchers, and publishers. It offers two programmatic integration surfaces for third-party platforms: a 1EdTech-certified LTI 1.3 / LTI Advantage integration, and the Turnitin Core API (TCA) — a RESTful API for submitting files, generating Similarity Reports, and displaying results in-workflow. TCA reference docs are credential-gated (existing customers and approved integration partners). Turnitin states SOC 2 compliance and operates international data centers. Gradescope is a Turnitin company.

## Developer
